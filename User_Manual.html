SanSan Data Matcher Web Application

အသုံးပြုသူလက်စွဲနှင့် စနစ်တပ်ဆင်ခြင်း လမ်းညွှန် (User Manual & Setup Guide)

🌐 Offline Version 1.0
အမြန်သွားရန်: မိတ်ဆက် စနစ်လိုအပ်ချက်များ တပ်ဆင်နည်း App စတင်ဖွင့်နည်း အသုံးပြုပုံ အဆင့်ဆင့် ကော်လံများ ရှင်းလင်းချက် ပြဿနာဖြေရှင်းခြင်း

📌 ၁။ မိတ်ဆက်နှင့် ရည်ရွယ်ချက် (Overview)

ဤ SanSan Data Matcher Web Application သည် SanSan စနစ်မှ ထုတ်ယူရရှိသော CSV Operation Records ဖိုင်များနှင့် ကုမ္ပဏီ၏ CIC Daily Capacity Excel ဖိုင် (.xlsx) ကြားရှိ အချက်အလက်များ (Match Rates) မှန်ကန်ကိုက်ညီမှု ရှိ/မရှိကို အလိုအလျောက် တိုက်ဆိုင်စစ်ဆေးပေးသည့် ကိရိယာဖြစ်ပါသည်။

ယခင်က လူကိုယ်တိုင် Excel တွင် Ctrl + F ဖြင့် ဝန်ထမ်းအမည်ရှာ၍ အချက်အလက်တစ်ခုချင်းစီ စစ်ဆေးခဲ့ရသော လုပ်ငန်းစဉ်ကို ယခု Web App အားဖြင့် စက္ကန့်ပိုင်းအတွင်း အချက်အလက်ရာပေါင်းများစွာကို တပြိုင်နက်တည်း အလိုအလျောက် စစ်ဆေးပေးပြီး အစီရင်ခံစာ ထုတ်ပေးနိုင်မည် ဖြစ်ပါသည်။

💻 ၂။ ကွန်ပျူတာ စနစ်လိုအပ်ချက်များ (System Requirements)

အမျိုးအစား အသေးစိတ် လိုအပ်ချက်
Operating System Windows 10 သို့မဟုတ် Windows 11 (64-bit)
Web Browser Google Chrome, Microsoft Edge, သို့မဟုတ် Mozilla Firefox
Python Environment Python Version 3.10 သို့မဟုတ် အထက် (Python 3.13 ထည့်သွင်းထားရန် အကြံပြုပါသည်)
လိုအပ်သော Python Packages streamlit (Web Interface အတွက်)
pandas (Data ဖတ်ရှုတွက်ချက်ရန်)
openpyxl (Excel ဖိုင်များ ဖတ်ရှုထုတ်လုပ်ရန်)

⚙️ ၃။ ပထမဆုံးအကြိမ် တပ်ဆင်နည်း (One-Time Setup)

အသုံးပြုမည့် ကွန်ပျူတာတွင် အောက်ပါအဆင့် (၂) ဆင့်အတိုင်း တစ်ကြိမ်သာ တပ်ဆင်ရန် လိုအပ်ပါသည် -

၁ Python သွင်းယူခြင်း (မရှိသေးပါက)

ကွန်ပျူတာတွင် Python မရှိသေးပါက တရားဝင် ဝဘ်ဆိုက် python.org မှ ဒေါင်းလုဒ်ရယူပါ။

⚠️ အထူးသတိပြုရန်: Python ကို Install လုပ်သည့်အခါ အောက်ခြေရှိ "Add python.exe to PATH" ဆိုသည့် checkbox လေးကို မဖြစ်မနေ အမှန်ခြစ် ပေးခဲ့ရပါမည်။
၂ လိုအပ်သော Library များကို အလိုအလျောက် သွင်းယူခြင်း

ဖိုဒါထဲရှိ install_requirements.bat ဖိုင်ကို Double-Click (၂ ချက်နှိပ်) လိုက်ရုံဖြင့် လိုအပ်သော Library များ အားလုံး အလိုအလျောက် သွင်းယူပေးသွားမည် ဖြစ်ပါသည်။

install_requirements.bat
အောင်မြင်သည့်အခါ: Command Prompt အမည်းရောင် Box တွင် "[အောင်မြင်ပါသည်] Package များ အားလုံး အောင်မြင်စွာ ထည့်သွင်းပြီးပါပြီ" ဟု ပြသပါမည်။

🚀 ၄။ Web App ကို စတင်ဖွင့်လှစ်နည်း (How to Launch)

နေ့စဉ် အသုံးပြုလိုသည့်အခါ အောက်ပါအတိုင်း လွယ်ကူစွာ စတင်နိုင်ပါသည် -

👉 1-Click Launch (အလွယ်ကူဆုံးနည်းလမ်း)

ဖိုဒါထဲရှိ Launch_WebApp.bat ကို Double-Click နှိပ်လိုက်ပါ။

ခဏအကြာတွင် သင့် ကွန်ပျူတာ၏ Web Browser (Chrome/Edge) တွင် Web App စာမျက်နှာ အလိုအလျောက် ပွင့်လာပါမည်။

အကယ်၍ Browser အလိုအလျောက် ပွင့်မလာပါက Browser ကို ဖွင့်ပြီး အောက်ပါလိပ်စာကို ရိုက်ထည့်နိုင်ပါသည် -

http://localhost:8501

📖 ၅။ အသုံးပြုပုံ အဆင့်ဆင့် လမ်းညွှန် (Step-by-Step User Guide)

ပုံ (၁) - Web App စတင်ဖွင့်လှစ်ချိန်တွင် တွေ့မြင်ရမည့် Dashboard မြင်ကွင်း
၁ ဖိုင်များ ထည့်သွင်းခြင်း (File Source)

ဘယ်ဘက် Sidebar ရှိ "Choose Input Mode" တွင် ရွေးချယ်နိုင်သော နည်းလမ်း (၂) မျိုး ရှိပါသည် -

  • Use Local Workspace Files (မူလနည်းလမ်း): ဖိုဒါထဲတွင် ရှိနှင့်ပြီးသား Excel နှင့် CSV ဖိုင်များကို အလိုအလျောက် ရှာဖွေပြီး ရွေးချယ်ပေးပါမည်။ ဖိုင်အသစ် ထပ်မတင်လိုပါက ဤနည်းလမ်းသည် အမြန်ဆန်ဆုံး ဖြစ်ပါသည်။
  • Upload New Files: ရက်စွဲအသစ်ဖြင့် အခြားဖိုင်များကို စစ်ဆေးလိုပါက Excel ဖိုင် (.xlsx) နှင့် CSV ဖိုင်များကို ကွန်ပျူတာထဲမှ Drag & Drop ဆွဲထည့်နိုင်ပါသည်။
💡 မှတ်ချက်: CSV ဖိုင် တင်သည့်အခါ 名刺 (Business Card) CSV နှင့် 項目選択 (Item Selection) CSV ဖိုင် (၂) မျိုးစလုံးကို တပြိုင်နက်တည်း ရွေးချယ် တင်သွင်းနိုင်ပါသည်။
၂ Excel နှင့် Field များကို သတ်မှတ်ခြင်း (Configuration)

စာမျက်နှာထိပ်ရှိ "⚙️ Excel & Mapping Configuration" ကဏ္ဍတွင် အောက်ပါတို့ကို လိုအပ်သလို ညှိယူနိုင်ပါသည် -

  • Excel Sheet to Check: စစ်ဆေးမည့် Sheet အမည် (မူလသတ်မှတ်ချက်: Monthly Record)
  • Header Row: Excel ၏ ခေါင်းစဉ်အတန်း နံပါတ် (မူလသတ်မှတ်ချက်: Row 3)
  • Excel User Identifier Column: ဝန်ထမ်းကုဒ်ပါသော ကော်လံ (မူလသတ်မှတ်ချက်: User Identifier)
  • Target Fields to Verify: စစ်ဆေးလိုသော အချက် (၁၂) ချက်ကို Checkbox ဖြင့် လိုအပ်သလို အမှန်ခြစ် ဖြုတ်/တပ် ပြုလုပ်နိုင်ပါသည်။
၃ ရလဒ် အနှစ်ချုပ်ကို ကြည့်ရှုခြင်း (Reviewing Results)

စနစ်မှ အချက်အလက်များကို အလိုအလျောက် တွက်ချက်ပြီး ကတ်ပြား (၄) ခုဖြင့် ရှင်းလင်းစွာ ဖော်ပြပေးပါမည် -

ကတ်ပြားအမည် အရောင် အဓိပ္ပာယ်
Total Values Checked အပြာရောင် စစ်ဆေးခဲ့သော စုစုပေါင်း ကိန်းဂဏန်း အရေအတွက် (ဥပမာ - ၅၃၉ ခု)
Matched Values အစိမ်းရောင် CSV နှင့် Excel ဖိုင် ၂ ခုစလုံးတွင် အတိအကျ ကိုက်ညီသော အရေအတွက် နှင့် ရာခိုင်နှုန်း (%)
Mismatches အနီရောင် တန်ဖိုး ကွဲလွဲနေသည့် အရေအတွက် (ဥပမာ - CSV တွင် 96.59 ဖြစ်ပြီး Excel တွင် 95.00 ဖြစ်နေခြင်း)
Missing / Unmatched အဝါရောင် CSV တွင် ပါပြီး Excel တွင် အကွက်လွတ်နေခြင်း သို့မဟုတ် Excel တွင် ရှိပြီး CSV တွင် မပါခြင်း
၄ အချက်အလက်များ စစ်ထုတ်ရှာဖွေခြင်း (Filter & Search)

အောက်ဘက်ရှိ "Comparison Details" ဇယားတွင် အချက်အလက်များကို အသေးစိတ် စစ်ဆေးနိုင်ပါသည် -

  • Filter by Status: Only Mismatches ကို ရွေးချယ်ပါက အမှားများကိုသာ သီးသန့် မြင်တွေ့ရမည်ဖြစ်ပြီး၊ All ရွေးချယ်ပါက အားလုံးကို ပြသပါမည်။
  • Filter by Field: စစ်ဆေးလိုသော ကော်လံတစ်ခုတည်း (ဥပမာ - Item Select သို့မဟုတ် Date) ကိုသာ ရွေးချယ် ကြည့်ရှုနိုင်ပါသည်။
  • Search Box: ရှာဖွေလိုသော ဝန်ထမ်း၏ User Identifier (ဥပမာ - iida_NiNiTun) သို့မဟုတ် Operator Name ကို ရိုက်ထည့်၍ ရှာဖွေနိုင်ပါသည်။
၅ Excel အစီရင်ခံစာ ဒေါင်းလုဒ် ရယူခြင်း (Export Report)

စာမျက်နှာ အောက်ဆုံးရှိ "Download Excel Report (.xlsx)" ခလုတ်ကို နှိပ်ပါက စစ်ဆေးထားသော အချက်အလက် အပြည့်အစုံကို အရောင်ခွဲခြား သတ်မှတ်ထားသည့် Excel ဖိုင်ဖြင့် ဒေါင်းလုဒ် ဆွဲယူနိုင်ပါသည် -

  • အစိမ်းရောင်ဆဲလ် (Light Green): ကိုက်ညီသော တန်ဖိုးများ (MATCH)
  • အနီရောင်ဆဲလ် (Light Red): ကွဲလွဲနေသော တန်ဖိုးများ (MISMATCH)
  • အဝါရောင်ဆဲလ် (Light Yellow): အကွက်လွတ်နေသော တန်ဖိုးများ (MISSING)

📊 ၆။ စစ်ဆေးသော ကော်လံများ ဖွဲ့စည်းပုံ (Field Mapping Table)

အပလီကေးရှင်းမှ အလိုအလျောက် ချိတ်ဆက်စစ်ဆေးပေးသော ကော်လံ (၁၂) မျိုးမှာ အောက်ပါအတိုင်း ဖြစ်ပါသည် -

စဉ် Field အမည် CSV မူရင်းအမည် Excel ကော်လံ Excel ကော်လံခေါင်းစဉ်
၁ Item Select 項目選択 CSV (matchRate) Column L Item Select
၂ Date temp: Date / 日付 Column I Date
၃ Email temp: Email / Email Column G Email
၄ Fax temp: FAX / FAX Column J Fax
၅ Full Name temp: full name / 氏名 Column K Full Name
၆ MOBILE temp: mobile / 携帯 Column R MOBILE
၇ TEL temp: TEL / TEL Column Q TEL
၈ URL temp: URL / URL Column H URL
၉ Address temp: Address / 住所 Column P Address
၁၀ Company Name temp: company / 会社 Column M Company Name
၁၁ Division Name temp: division / 部署 Column N Division Name
၁၂ Position Name temp: position / 役職 Column O Position Name

🛠️ ၇။ မကြာခဏ ကြုံတွေ့ရတတ်သော ပြဿနာများနှင့် ဖြေရှင်းနည်း (Troubleshooting)

Q1: Launch_WebApp.bat ကို နှိပ်သော်လည်း အမည်းရောင် Box ခဏ ပေါ်လာပြီး ပိတ်သွားပါသည်

အကြောင်းရင်း: ကွန်ပျူတာတွင် Python မသွင်းရသေးခြင်း သို့မဟုတ် Python PATH မချိတ်ဆက်ထားခြင်းကြောင့် ဖြစ်နိုင်ပါသည်။

ဖြေရှင်းနည်း: Python ကို ပြန်လည် Install ပြုလုပ်ပြီး "Add python.exe to PATH" ကို အမှန်ခြစ် ပေးပါ။ ထို့နောက် Command Prompt ဖွင့်၍ python --version ရိုက်နှိပ်ပြီး စစ်ဆေးပါ။

Q2: "No module named 'streamlit'" သို့မဟုတ် Library အမှား ပြသနေပါသည်

ဖြေရှင်းနည်း: ဖိုဒါထဲရှိ install_requirements.bat ကို Double-Click ပြန်လည် နှိပ်ပြီး Library များကို သွင်းယူပေးပါ။

Q3: Port 8501 is already in use ဆိုသော အမှား ပြသနေပါသည်

အကြောင်းရင်း: အရင်ဖွင့်ထားသော Streamlit Web App မပိတ်ရသေးဘဲ နောက်တစ်ခု ထပ်ဖွင့်ခြင်း ဖြစ်ပါသည်။

ဖြေရှင်းနည်း: ယခင်ဖွင့်ထားသော Command Prompt Box ကို ပိတ်လိုက်ပါ သို့မဟုတ် Browser တွင် ဖွင့်ထားပြီးသား tab သို့ တိုက်ရိုက် သွားရောက် အသုံးပြုနိုင်ပါသည်။

Q4: အင်တာနက် လိုင်းမရှိဘဲ သုံးစွဲနိုင်ပါသလား?

အဖြေ: ဟုတ်ကဲ့၊ သုံးစွဲနိုင်ပါသည်။ ပထမဆုံး အကြိမ် Library များ ဒေါင်းလုဒ်ယူချိန် (install_requirements.bat ပြုလုပ်ချိန်) မှလွဲ၍ နေ့စဉ် ပုံမှန် အသုံးပြုရာတွင် အင်တာနက် လုံးဝ ချိတ်ဆက်ရန် မလိုဘဲ Offline အပြည့်အဝ အသုံးပြုနိုင်ပါသည်။

📁 ၈။ ဖိုဒါအတွင်း ပါဝင်သော ဖိုင်များ အကျဉ်းချုပ်
